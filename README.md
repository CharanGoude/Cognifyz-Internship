# Cognifyz-Internship



A sleek, modern user interface template styled with CSS gradients, glassmorphism, and responsive design. Perfect for dashboards, portals, or web apps.

## Features

- **Gradient backgrounds** for a vibrant look
- **Glassmorphism containers** with blur and transparency
- **Modern buttons** with animated hover effects
- **Responsive design** for mobile and desktop
- **Styled tables, forms, and alerts**


## Customization

- Edit `style.css` to change colors, fonts, or layout.
- Add your HTML structure and components as needed.
